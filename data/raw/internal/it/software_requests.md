# Software requests

Last reviewed: 2026-03-02 by Sam Ortiz, IT lead

## Where to request software

All software requests go through the IT portal, whether it is a new tool, an upgraded license tier, or a browser extension that needs an exception from the managed Chrome policy.

1. Log in to the IT portal with Okta SSO.
2. Select "New request," then "Software."
3. Fill in the tool name, business justification, and whether it needs access to customer data.
4. Submit. The request routes to IT for a security and licensing check.

## Response times

IT answers new tickets within 24 hours on business days. A straightforward request (a Slack extension, a personal 1Password vault add-on) is often approved same day. A request that touches customer data or requires a new vendor contract takes longer, since it needs a security review from Tom Brennan's team and, above $5,000 in annual cost, a procurement review through Coupa.

## Pre-approved tools

The following are pre-approved and self-serve through the Kandji app catalog, no ticket required:

- Slack, Jira, Confluence, GitHub Desktop
- Google Workspace apps
- 1Password browser extension
- Zoom, standard tier

## Tools that need approval

- Any AI coding or writing tool not already on the approved list, because of data handling review
- Browser extensions requesting access to all site data
- Any tool that stores or processes customer PII, which needs sign-off from Ruth Adeyemi's team in addition to IT
- Paid tools over $500/year per seat, which need your manager's budget approval attached to the ticket

## Engineering-specific requests

Engineers requesting access to production infrastructure, a new SaaS dev tool, or an API key for a third-party service should tag the ticket "engineering" and include the GitHub repo it relates to. Marcus Lee's team reviews infrastructure-adjacent requests weekly, on Wednesdays.

## Denials and appeals

If a request is denied, the ticket includes the reason (security, cost, duplicate of an existing tool, and so on). To appeal, reply on the same ticket with additional justification rather than opening a new one. A second denial on the same request goes to the relevant VP for a final call.

## Software you already have

Before requesting something new, check the internal tool list in Confluence under IT, since Kestrel already licenses many common categories: project tracking (Jira), documentation (Confluence), CRM (Salesforce), expense management (Expensify), procurement (Coupa), and password management (1Password). Duplicate requests for tools in an already-licensed category are usually declined in favor of the existing tool.

## Removing or canceling software

If you stop using a licensed tool, tell IT through the portal so the seat can be reclaimed. IT also runs a quarterly license audit and reaches out directly to anyone with an inactive seat for more than 60 days.

## FAQ

**Can I expense software directly instead of going through IT?** No. Any software purchase, even a small one, needs to go through the IT portal first so it is tracked and licensed correctly. Expensify reimbursement without an approved IT ticket may be rejected.

**How long does a security review take for a new vendor?** Typically 5 to 10 business days, depending on the vendor's own security documentation.
